# davegooding.com

Personal site. Plain Jekyll, built by GitHub Pages.

- Publications: `_data/publications.yml`
- Career timeline: `_data/work.yml`
- Posts: `_posts/`. How to write one, and the pre-publish checklist: `WRITING.md`
- Styles: `assets/css/main.css`

Run locally:

    bundle install
    bundle exec jekyll serve --drafts
